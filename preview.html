오늘도 힘내라구!
햄찌는 혼자 돌아다니며 쉬기, 세수하기, 장난치기, 잠자기를 랜덤으로 해요.
햄스터를 우클릭하면 Talk Off, 잠시 멈추기, 다시 움직이기, Exit 메뉴를 체험할 수 있어요. 미리보기의 Exit는 동작을 멈추며, 실제 EXE에서는 프로그램을 종료해요. 이 미리보기는 HTML 파일 하나에 이미지가 모두 포함되어 있어요. 별도의 이미지 폴더나 Python 설치가 필요하지 않아요. 브라우저 안에서 동작을 체험하는 버전이며, 실제 Windows 바탕화면 위에 뜨는 펫은 아래 프로젝트의 GitHub Actions 빌드로 만들 수 있어요.
